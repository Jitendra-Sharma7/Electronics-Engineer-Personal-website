- Dark-first visual experience
- Optional light mode
- Large typography
- Bento-grid layouts
- Smooth animations
- Subtle 3D interactions
- Micro-interactions
- Glassmorphism where appropriate
- Clean spacing and hierarchy
- Mobile-first responsive design
- Accessibility-focused UI

The design should feel **professional rather than flashy**, with animations used to improve the user experience instead of distracting from the content.

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Jitendra83-coder/Electronics-Engineer-Personal-website.git
```

Navigate to the project:

```bash
cd Electronics-Engineer-Personal-website
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

# 🔐 Environment Variables

Create a `.env.local` file:

```env
DATABASE_URL=

NEXTAUTH_SECRET=

GITHUB_TOKEN=

NEXT_PUBLIC_SITE_URL=

EMAIL_SERVER=

EMAIL_FROM=

AWS_ACCESS_KEY_ID=

AWS_SECRET_ACCESS_KEY=

AWS_REGION=

AWS_S3_BUCKET=
```

Never commit sensitive credentials or environment variables to GitHub.

# 🗄️ Database

If PostgreSQL and Prisma are used:

```bash
npx prisma generate
```

Run migrations:

```bash
npx prisma migrate dev
```

Open Prisma Studio:

```bash
npx prisma studio
```
